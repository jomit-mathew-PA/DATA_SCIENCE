**Blinkit Sales Analysis Dashboard | Microsoft Excel**
Project Overview
This project focuses on analyzing Blinkit's sales data using Microsoft Excel to understand product performance, outlet sales, customer ratings, and business trends.
An interactive Excel dashboard was developed using PivotTables, PivotCharts, slicers, and data analysis techniques to generate meaningful business insights.
Dataset Description
The dataset contains the following columns:
**Column  **              **Description**

Item Fat Content          Fat category of the product
Item Identifier           Unique product identification number
Item Type                 Category of the product
Outlet Establishment Year  Year the outlet was established
Outlet Identifier         Unique outlet identification number
Outlet Location Type      Classification of outlet location
Outlet Size               Size of the outlet
Outlet Type               Category of outlet
Item Visibility           Visibility percentage of the product
Item Weight               Weight of the product
Sales                     Sales generated by the product
Rating                    Customer rating of the product
